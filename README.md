# 🚗 Conducir Seguro — Un Minuto que Protege

## Sistema de Verificación Cognitiva para la Gestión del Riesgo Vial

Conducir Seguro es una aplicación web orientada a la **prevención y gestión del riesgo vial**.

El proyecto propone incorporar una instancia breve de verificación previa a la conducción, con el objetivo de observar determinadas **condiciones funcionales del momento** relacionadas con una conducción segura.

La propuesta busca complementar las medidas existentes de seguridad vial mediante una nueva capa preventiva aplicada **antes de iniciar la conducción**.

---

## 🎯 Objetivo

Desarrollar una herramienta digital que permita realizar una verificación breve del estado funcional del conductor antes de iniciar la conducción.

El sistema busca:

* Verificar condiciones funcionales del momento.
* Registrar los resultados obtenidos.
* Detectar posibles variaciones respecto de parámetros de referencia.
* Generar alertas preventivas cuando corresponda.
* Favorecer la toma de decisiones orientadas a la prevención.
* Promover hábitos de autocuidado y seguridad vial.

---

## 🧠 ¿Qué verifica?

La aplicación está orientada a observar indicadores funcionales vinculados con:

* Nivel de atención y alerta.
* Capacidad de respuesta.
* Tiempo de reacción.
* Control inhibitorio.
* Consistencia general frente a estímulos.

La verificación está pensada como una instancia breve previa a la conducción.

---

## 🧪 Funcionamiento general

El flujo principal de la aplicación es:

1. El usuario accede al sistema.
2. Se muestran las instrucciones de la verificación.
3. El usuario realiza una prueba breve.
4. El sistema registra las respuestas y los tiempos obtenidos.
5. Se procesan los resultados.
6. Se comparan los resultados con parámetros de referencia.
7. El sistema muestra una respuesta preventiva.
8. Los resultados pueden almacenarse para su posterior consulta y análisis.
