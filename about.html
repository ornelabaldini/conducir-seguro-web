SOBRE EL PROYECTO

Conducir Seguro

Un Minuto que Protege

Sistema de Verificación Cognitiva para la Gestión del Riesgo Vial.

¿POR QUÉ NACIÓ?

Una mirada preventiva

Observamos que muchas estrategias de seguridad vial actúan durante la conducción, después de una infracción o tras un siniestro. Sin embargo, existe una oportunidad clave: incorporar una instancia antes de comenzar a conducir.

Conducir Seguro nace para aprovechar esa ventana preventiva, ayudando a reducir riesgos desde el inicio.

-->
UN MINUTO ANTES DE CONDUCIR

Así funciona

Antes de conducir

La persona inicia el test de verificación cognitiva.

→

Test

Se presentan estímulos y se analizan variables como: tiempo de reacción, atención, concentración, memoria operativa y velocidad de respuesta.

→

Resultados

Se procesan los resultados y se contrastan con registros individuales previos.

→

Referencia individual

Se construye una referencia personalizada de desempeño.

→

Información para la prevención

Los datos se transforman en información útil para reducir riesgos y promover una conducción más segura.

HACIA DÓNDE APUNTA EL PROYECTO

Hacia el futuro

La plataforma seguirá creciendo con un plan de desarrollo que incluye la construcción de referencias individuales, el seguimiento longitudinal, la identificación de desvíos, la calibración, la validación operativa y la ampliación progresiva del sistema.
